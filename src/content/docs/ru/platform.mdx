## TL;DR

Для этого туториала мы используем **Starlight** (Astro). Он даёт встроенную интернационализацию с fallback-страницами, бесплатный офлайн-поиск (Pagefind), MDX и чистую тему по умолчанию — без веса сборки Docusaurus и без привязки к Next.js, как у Fumadocs.

## Почему отдельный сайт туториала

Туториал — это не `README.md` и не папка `docs/` внутри репозитория с кодом. Он живёт в отдельном репозитории (`kwebhub/zkpool-tutorial`) по трём причинам:

1. **Другая аудитория.** Репозиторий с кодом — для разработчиков, которые хотят читать исходники. Туториал — для тех, кому нужен ведомый путь.
2. **Другой ритм.** Код меняется на каждом коммите. Туториал меняется, когда этап завершён.
3. **Другое развёртывание.** Туториал — статический сайт. Его можно бесплатно разместить на GitHub Pages, Netlify или Vercel — независимо от репозитория с кодом.

## Кандидаты

Три фреймворка документации доминируют в 2026 году:

| Фреймворк | Встроенный поиск | Встроенная i18n | Скорость сборки | JS по умолчанию |
|---|---|---|---|---|
| **Starlight** (Astro) | Pagefind, офлайн | Да, с fallback | Быстрая | Нет |
| **Docusaurus** (React) | Algolia (нужен аккаунт) | Да | Медленная | React runtime |
| **Fumadocs** (Next.js) | Да | Частичная | Средняя | React runtime |

## Почему Starlight

**Встроенная i18n с fallback.** Starlight поставляется с маршрутизацией по локалям. Страницы без перевода откатываются на язык по умолчанию и показывают уведомление — ни битых ссылок, ни дублированного контента. Для двуязычного туториала EN/RU это решающая возможность.

**Бесплатный офлайн-поиск.** Pagefind индексирует собранный сайт на этапе сборки. Никаких аккаунтов Algolia, никаких API-ключей, никаких платежей за запросы. Поиск работает на GitHub Pages и офлайн.

**Нет клиентского фреймворка.** Starlight по умолчанию не отправляет JavaScript. Страницы загружаются быстро, Lighthouse остаётся высоким, и нет React-runtime, который нужно поддерживать параллельно с контентом туториала.

**MDX из коробки.** Каждая страница — `.mdx`. Можно встраивать интерактивные компоненты (чеклисты, табы, выноски), не покидая фреймворк.

**Экосистема Astro.** Если позже понадобится кастомный компонент — живой чекер ZK-доказательств, интерактивный визуализатор схемы — Astro поддерживает React, Vue, Svelte и Solid как «острова». Мы не привязаны к одному UI-фреймворку.

## Почему не Docusaurus

Docusaurus зрелый и имеет большую экосистему плагинов. Но:

- Время сборки растёт с числом страниц; туториал на 100 страниц пересобирается 5–20 секунд.
- Поиск требует аккаунта Algolia DocSearch (бесплатно для OSS, но это внешняя зависимость).
- i18n работает, но семантика fallback слабее: отсутствующие страницы отдают 404 вместо отката.
- Он отправляет React-runtime — ненужный вес для контентного сайта.

## Почему не Fumadocs

Fumadocs визуально современен и быстр, но:

- Требует проекта на Next.js App Router. Наш туториал — не Next.js приложение, и его добавление означает поддержку второго стека (Next.js, React, конфиг TypeScript) параллельно с Astro.
- Поддержка i18n частичная и менее документирована, чем в Starlight.
- Экосистема моложе; меньше примеров и сторонних плагинов.

## Что мы настраиваем

В `astro.config.mjs`:

- `defaultLocale: 'en'` — английский язык по умолчанию.
- `locales: { en, ru }` — две локали, русская с префиксом `/ru/`.
- `sidebar` — сгруппирован по этапам, с `translations` для русских меток.
- `social` — одна ссылка на GitHub `kwebhub/zkpool-mesh`.

Контент лежит в `src/content/docs/en/` и `src/content/docs/ru/`. Английские страницы отдаются по `/...`, русские — по `/ru/...`.

## Частые ошибки

**`The collection "i18n" does not exist or is empty.`**
Вы включили `locales` в конфиге, но не создали `src/content/docs/en/` и `src/content/docs/ru/`. Starlight ожидает контент в подкаталогах по локалям, когда i18n включена.

**Страницы отдают 404 после смены языка.**
Русской страницы ещё нет. Fallback Starlight работает только когда локаль правильно настроена и страница языка по умолчанию существует. Создайте пару в `ru/` или позвольте fallback показать английскую страницу с уведомлением.

**Поиск ничего не возвращает.**
Pagefind индексирует собранный сайт, а не dev-сервер. Запустите `pnpm build` и `pnpm preview`, чтобы проверить поиск.

## Воспроизведение

```bash
npm create astro@latest . -- --template starlight --no-install --no-git --typescript strict
# переключаемся на pnpm
corepack enable && corepack prepare pnpm@latest --activate
pnpm install
pnpm approve-builds   # одобрить esbuild
pnpm astro telemetry disable
```

Затем отредактируйте `astro.config.mjs`, добавив `defaultLocale` и `locales`.
