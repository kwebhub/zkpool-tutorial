Добро пожаловать в туториал **zkpool-mesh**.

Этот туториал документирует создание ZK приватного пула на Solana — от первого схемы до production-развёртывания в Kubernetes — с микросервисами, DevSecOps и наблюдаемостью.

## Что вы построите

- Схему Groth16 на Noir/BN254 для приватных переводов SOL
- Solana Anchor программу с верификатором
- Микросервисный бэкенд (Rust, Node.js)
- Vue 3 фронтенд с ZK-пайплайном свидетеля
- E2E-тесты с Playwright
- Infrastructure as Code с Terraform и Ansible
- Кластер K3s с GitOps (Argo CD)
- Полный DevSecOps конвейер (SAST, SBOM, подпись, политики)

## Как читать туториал

Каждый этап — глава. Каждая глава отвечает на три вопроса:

1. **Почему** эта технология используется здесь.
2. **Как** её настроить.
3. **Что** проверить, чтобы убедиться, что она работает.

Английская версия — по умолчанию. Русская версия доступна по `/ru/` с откатом на английский для непереведённых страниц.
